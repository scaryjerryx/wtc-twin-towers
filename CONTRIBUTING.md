# Contributing

Thank you for your interest in contributing to the World Trade Center Evidence Engine.

## Project Philosophy

This project follows an evidence-first approach to historical research and reconstruction.

Key principles:

- Evidence over assumptions
- Provenance for every claim
- Traceable citations
- Transparent verification
- Reproducible research workflows
- Preservation of uncertainty and conflicting evidence

## Development Workflow

All significant work follows the project process:

```text
Audit
↓
Plan
↓
Review
↓
Implement
↓
Verify
↓
Document
↓
Commit
```

## Before Making Changes

Please review:

- README.md
- docs/ARCHITECTURE.md
- docs/CURRENT_STATE.md
- docs/NEXT_TASK.md
- docs/AI_HANDOFF.md

Understand the currently active milestone before making modifications.

## Database Changes

Database modifications require:

- Review
- Verification
- Migration planning
- Safety checks
- Documentation updates

Do not make unreviewed database changes.

## Evidence Handling

Do not:

- Delete evidence records
- Remove provenance information
- Replace original source references
- Modify historical records without documentation

Evidence should remain traceable and auditable.

## Pull Requests

When submitting changes:

1. Keep changes scoped to a single objective.
2. Explain the reason for the change.
3. Document verification steps.
4. Update documentation when required.
5. Avoid unrelated refactoring.

## Questions

For significant architectural or workflow changes, open an issue or discussion before implementation.
