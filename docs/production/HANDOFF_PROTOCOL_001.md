# HANDOFF PROTOCOL

To ensure seamless autonomous execution between AI agents, strict handoff protocols must be observed.

## Milestone Handoff
When a shot is completed (e.g., Realism Pass V1 is Approved):
1. Team C generates the `SHOTXXX_POSTMORTEM_001.md`.
2. Team C moves all previous reference/criteria documents to `/docs/archive/`.
3. Team C resets the Production Board to the initialization state for the next target.
4. Team A, B, and D statuses are cleared of the previous shot's data and prepped for the new objective.

## Inter-Team Handoff
- **Team B -> Team A**: Team A cannot begin blockout implementation until `SHOTXXX_REFERENCE.md` is generated by Team B.
- **Team A -> Team D**: Team A signals completion by generating `SHOTXXX_BLOCKOUT_V1.png` and updating `TEAM_A_STATUS_001.md`. Team D then autonomously triggers its review cycle.
- **Team D -> Team C**: If Team D scores the milestone appropriately, it updates `TEAM_D_REVIEW_001.md` with "MILESTONE MET". Team C detects this and escalates to the Project Director.

## Error Recovery Handoff
If Team A encounters a Technical Blocker:
1. Team A updates `TEAM_A_STATUS_001.md` setting state to `BLOCKED`.
2. Team C halts the Production Board and escalates immediately to the Project Director for intervention (e.g., Quota Exhaustion).
