# High-Value Archive Targets

## Date

August 10, 2026

## Purpose

Identify the highest-value archive collections that could close the largest number of reconstruction evidence gaps for the World Trade Center complex.

---

## Rank 1: NIST WTC Investigation Reports Collection

| Field | Value |
|---|---|
| **Archive name** | NIST Federal Building and Fire Safety Investigation of the World Trade Center Disaster |
| **Repository** | Internet Archive — `https://archive.org/details/NIST_WTC_Investigation_Reports-861612` |
| **Estimated file count** | 84 items (NCSTAR 1-1 through 1-9, appendices, and supplementary reports) |
| **Estimated size** | 2-5GB (comprehensive multi-volume report series) |
| **Evidence categories covered** | Structural engineering, architectural floor plans, site plans, exterior wall analysis, mechanical systems, fire protection, occupant egress, visual evidence, timeline analysis, foundation documentation |
| **Reconstruction value** | **Critical** — This is the single most comprehensive publicly available collection of WTC structural and architectural documentation. The NCSTAR reports were produced by NIST as part of the federal investigation and contain reproduced floor plans, structural framing plans, site diagrams, exterior wall panel schedules, mechanical floor layouts, and foundation documentation as embedded figures. |
| **Critical gaps addressed** | CG-2 (Floor Plans), CG-3 (Site Plans), CG-4 (Exterior Wall Analysis), IG-3 (WTC 7 Documentation), IG-4 (MEP — partial), IG-6 (Foundation — partial) |
| **Access** | Public domain (U.S. government work). Freely downloadable. |
| **Download method** | Manual browse and download from Internet Archive collection page. |

## Rank 3: Library of Congress Gottscho-Schleisner Collection

| Field | Value |
|---|---|
| **Archive name** | Gottscho-Schleisner Photograph Collection |
| **Repository** | Library of Congress — `https://www.loc.gov/pictures/collection/gsc/` |
| **Estimated file count** | 100-500 WTC-related photographs (estimated from collection scope) |
| **Estimated size** | 500MB-2GB (high-resolution TIFF/JPEG photographs) |
| **Evidence categories covered** | Construction photographs, architectural photography, interior photographs, exterior elevations, site context, plaza documentation |
| **Reconstruction value** | **High** — The Gottscho-Schleisner firm was the premier architectural photography firm in New York. They documented major construction projects including the WTC. Their collection would provide professional-quality photographs of the towers under construction, completed exteriors, lobbies, interior spaces, and the plaza. These photographs are the primary visual evidence for reconstruction. |
| **Critical gaps addressed** | IG-1 (Construction Photographs), IG-2 (Interior Photographs), IG-5 (Architectural Elevations — visual reference) |
| **Access** | Public domain (Library of Congress collection). Freely downloadable. |
| **Download method** | Search `https://www.loc.gov/pictures/collection/gsc/` for "World Trade Center". Download individual high-resolution TIFF files. |
